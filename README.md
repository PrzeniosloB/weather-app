# Aplikacja Pogodowa (Weather App)

Aplikacja webowa sprawdzająca aktualną temperaturę oraz prędkość wiatru dla dowolnego miasta na świecie.

## Technologie

* **HTML5 & CSS3** – struktura i nowoczesny wygląd
* **JavaScript (ES6+)** – asynchroniczne zapytania do API (`async/await`, `fetch`)
* **Open-Meteo API** – darmowe źródło danych geolokalizacyjnych i pogodowych w czasie rzeczywistym

## Funkcjonalności

* Wyszukiwanie pogody dla dowolnego miasta (z obsługą klawisza Enter).
* Automatyczne pobieranie współrzędnych i danych meteorologicznych.
* Obsługa błędów (np. gdy miasto nie istnieje).
